# Разработка

Начальный этап: контракт и технические проверки. Windows x64, Rust 1.100.0 MSVC;
компилятор установлен через официальный rustup, версия закреплена rust-toolchain.toml.
Проверено 2026-11-18 на текущем Windows-окружении.

Пакет dagaz-protocol содержит модели библиотеки, качеств, загрузок, заданий,
синхронизации, привязки и управления воспроизведением. Семантика MetadataPatch:
отсутствующее поле не меняет тег, null очищает, значение заменяет.
PlaybackState сохраняет конкретную перестановку play_order и различает повторные
вхождения одного трека. У пустой очереди queue_index и track_id равны null.

Запуск из корня: cargo test --workspace. Форматирование: cargo fmt --all.
Статическая проверка: cargo clippy --workspace --all-targets -- -D warnings.
Workspace содержит protocol и сервер; текущие проверки выполняются на Windows.

P1 завершён: опубликован генерируемый OpenAPI 3.1 и общие JSON-примеры.
Регенерация: cargo run -p dagaz-protocol --example export_openapi.
api/openapi.yaml содержит JSON (это допустимая YAML-форма); тест проверяет,
что файл совпадает с генератором, а примеры соответствуют схемам.
Семантические проверки содержимого файлов/владения/ревизий выполняются сервером.

P4: отдельная проверка Lofty, см. docs/validation/metadata.md.
Для FFmpeg используется локальный Docker-образ, установка FFmpeg на Windows не нужна.
P5: Range, multipart и восстановление RustFS проверены локально в Docker,
см. docs/validation/storage.md. Проверки публикации ревизий с БД ещё впереди.
P3: Android-прототип установлен на физический Poco X8 Pro (Android 16);
форматы, поток, скачивание, холодный офлайн и короткая блокировка экрана проверены.
Ограничения и команды: docs/validation/android-media.md.
P2: GPUI-прототип собран и открыт; кириллица, поиск и диалог файлов проверены.
Тесты Rodio проверяют поток до полной загрузки, обрыв, перемотку и форматы;
см. docs/validation/windows-audio.md. Нативные SMTC pause/play/stop проверены;
физические клавиши гарнитуры пока не проверены.
P6: профили MP3 320/128, сохранение тегов/обложки и повторное использование
исходника проверены; оба профиля воспроизводятся и перематываются в Rodio/Media3.
Замеры на реальном VPS ещё впереди: docs/validation/transcode.md.
S1: сервер привязывает устройства одноразовыми кодами, хранит хеши токенов,
выдаёт список устройств и отзывает доступ. Тесты используют настоящие HTTP,
SQLite и изолированный RustFS. Запуск и ограничения: apps/server/README.md.
S2: загрузка частями с SHA-256/смещением и ключами повторов, восстановление после
перезапуска и долговечный импорт в RustFS реализованы. WAV/MP3/FLAC определяются
по содержимому; точные повторы не создают новые треки. Проверены multipart resume
и восстановление после записи S3 до публикации в SQLite.
Каталог для клиентов и потоковая выдача на сервере ещё не реализованы.
Прототипы в experiments — отдельные проекты,
они не входят в корневой cargo test и не являются готовыми клиентами.
