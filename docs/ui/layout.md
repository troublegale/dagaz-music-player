# Общая компоновка Dagaz

Первый вариант для обсуждения. Демонстрационные названия, обложки и счётчики не
являются пользовательской библиотекой. Это макеты нативных клиентов.

Windows: [макет](windows-layout.svg), 1440×900. Слева библиотека,
скачанное и плейлисты; сверху постоянный поиск и добавление файлов. Песни,
альбомы и исполнители — представления одной библиотеки. Основной список
показывает название, исполнителя, альбом, локальную доступность и время.
Справа раскрываемая очередь, снизу постоянный плеер и смена устройства.
В узком окне очередь закрывается, второстепенные столбцы скрываются.

Android: [макет](android-layout.svg), 412×915. Снизу библиотека, поиск и
скачанное; над ними мини-плеер, открывающий полный экран воспроизведения.
Добавление доступно в верхней части библиотеки. Поиск находится в нижней навигации; верхняя строка поиска и приветственный заголовок отсутствуют. Системные панели
учитываются через insets. В узком окне альбомы остаются двухколоночными,
длинные подписи сокращаются; размеры текста следуют системному масштабированию.

Основа: спокойная тёмная палитра, тёплый зелёный акцент, Segoe UI на Windows
и системный шрифт на Android. Цвета черновика: фон #151B24, навигация #0F141C,
поверхность #202A37, основной текст #E8EDF3, вторичный #91A0B4,
акцент #9CE6C6. В реализации используются штатные компоненты GPUI Kit/Compose,
а интерактивные элементы имеют видимый фокус, подписи для доступности и
достаточные области нажатия. Символьные значки макета заменяются иконками.

Доступность скачанного отображается у самого трека во всех подборках.
Ошибки и ожидание сети показываются словами, не одним цветом. Редактирование
тегов и добавление в плейлист доступны из контекстного меню и выделения.
Пустая библиотека предлагает добавить музыку; при отсутствии подключения
показываются сохранённые записи и доступные офлайн треки.

Экран подключения: адрес сервера, одноразовый код, имя устройства, действие
«Подключить». Ошибка сохраняет введённый адрес; недействительный/отозванный
доступ предлагает привязку заново. Приватный токен в интерфейсе не показывается.

Обратная связь: пользователь принял общее направление. По его замечаниям убраны отдельный поиск из бокового меню Windows и верхние поиск/заголовок «Твоя музыка» на Android.
