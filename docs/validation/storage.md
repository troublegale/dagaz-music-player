# RustFS storage probe — 2026-11-18

Окружение: Rust 1.100.0 MSVC, AWS SDK S3 1.160.0, RustFS 1.0.6 (linux/amd64),
Docker Desktop. Образ закреплён digest в deploy/compose.test.yaml.

Запуск на Windows: powershell -ExecutionPolicy Bypass -File experiments/storage/run.ps1
Запуск использует только отдельный сервис dagaz-storage-validation и loopback-порт 19000.
Скрипт создаёт случайные тестовые ключи в игнорируемом deploy/.env.test;
в репозиторий ключи не включаются. Уже существующий файл переиспользуется.

Результат: multipart_and_revision_ranges PASS, Clippy без предупреждений.

Проверено реальным SDK:
- Put/Get и Range bytes=2-5 возвращает cdef с Content-Range.
- Отдельные ключи двух ревизий сохраняют старые байты.
- If-Match другой ревизии даёт HTTP 412.
- Незавершённая multipart-загрузка недоступна как объект (HTTP 404).
- Multipart с первой частью 5 МиБ переживает рестарт контейнера; ListParts позволяет продолжить.
- Завершённый объект также доступен после рестарта.
- После второй части и Complete чтение диапазона внутри второй части возвращает нужные байты.
- Abort отменяет загрузку с переданной частью; список multipart пуст, готовые объекты сохраняются.
- Успешный прогон удаляет только свой уникальный bucket/объекты. Остатки аварийного прогона
  могут оставаться в отдельном тестовом томе; пользовательская библиотека здесь не используется.

Найденные условия интеграции:
- Access key нельзя генерировать обычным Base64: символ / нарушает разбор Credential scope SigV4.
  Здесь используются 20 случайных hex-символов; secret — отдельные случайные 32 байта в Base64.
- Случайный публикуемый Docker-порт меняется при restart. Для этой проверки закреплён 19000;
  занятый порт приводит к явному отказу запуска.
- SDK использует явные operation/attempt/connect/read timeouts, чтобы сбой сервиса не зависал.
- ETag считается непрозрачным идентификатором, а не SHA-256 файла.

Границы: это проверка S3-семантики. Сбой между S3 и коммитом SQLite и удаление осиротевших
ревизий проверяются в S5/S8 после создания серверного кода; выдавать их за проверенные сейчас нельзя.
Для остановки только тестового сервиса:
`docker compose --env-file deploy/.env.test -f deploy/compose.test.yaml stop`
Том не удаляется этой командой.
