# Dagaz Windows: подключение к серверу

Первый нативный экран GPUI Kit: адрес сервера, одноразовый код и имя устройства.
После привязки приложение сохраняет подключение и проверяет его при запуске.
Библиотека, аудиоплеер и офлайн-функции продуктового клиента будут добавлены
следующими этапами; этот экран не является готовым музыкальным плеером.

```text
cargo run --release -p dagaz-windows --features ui
```

Сборка: `target/release/dagaz-windows.exe`. Профиль:
`%LOCALAPPDATA%\Dagaz`; `connection.json` содержит адрес, ID устройства и токен,
зашифрованный Windows DPAPI для текущего пользователя. Замена файла атомарная.
Ошибки расшифровки и отозванный доступ требуют новой привязки. Именованный mutex
удерживает один экземпляр для профиля до завершения процесса, до создания аудио.

Принимается HTTPS без логина, пути, query и fragment. Для локальных тестов
разрешён HTTP на loopback IP; `localhost` вместо IP пока не принимается.
Редиректы не выполняются, токен отправляется только на origin своего сервера.
Сетевые запросы имеют ограничение времени; сеть, файловые операции и DPAPI
выполняются вне потока интерфейса. Ошибка не очищает введённый адрес.

Макеты и учтённые замечания: [общая компоновка](../../docs/ui/layout.md).
Проверки и ограничения: [результаты](../../docs/validation/windows-client.md).
